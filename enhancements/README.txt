SolidCraft enhancements — aporicho/solidcraft

这是基于官方 v0.30.1 的独立 fork，不是官方可加载插件。
铝型材推荐用法：创建/选中一根型材 → 点击模型上的蓝色“＋”接出下一根 → 拖动或输入长度 → 确认。两端的黄色按钮用于添加连接件。骨架是可选的批量方式。

原版安装文件与增强版分别保留。新增型材特征与固定型号杆件需要支持相应新格式的增强版打开。

分支：enhancements
上游：upstream -> tangency-labs/solidcraft（禁止推送）
自己的仓库：origin -> aporicho/solidcraft
基线：v0.30.1 / 8e2b0cd60d14b4152b12b8f1fdb2bcfdcd8c52f4

增强：固定毫米网格、捕捉范围、圆心拖动网格、在线与网格同时吸附。
模型页新增“选择增强”：环选、外边缘；“历史”里新增“节点视图”。
外边缘：先选平面，再点击图标，只选最外圈，不包含内部孔、槽的内圈。
环选：先选边，再点击图标，补齐该边所在的一圈；可用于孔口。
一条边有两个相邻面时优先使用面积较大的平面，也可同时选面明确指定。
当前只支持平面上的闭合轮廓，不把三角网格线作为可倒角的真实边。
选择完成后可直接打开倒圆角或倒角，预选边会被带入。

构建：sh enhancements/build.sh
完整检查：sh enhancements/check.sh（限制并发，避免占满桌面电脑内存）
源代码增量包：先 git add 新增文件，再 sh enhancements/package.sh。
补丁包基于精确的 v0.30.1；在新的官方源码副本中校验 SHA256SUMS，
然后 git apply --check changes.patch，确认后 git apply changes.patch，再构建。
不得向正在使用的原版安装文件直接应用源码补丁。

更新上游时先检查差异，在独立分支合并并验证，再更新 manifest 中的基线。
不要自动跨版本应用旧补丁，不向 upstream 推送，不改写自己的已发布历史。
新增图标保留 Open 状态供用户审阅；未修改官方已接受的图标。

节点视图：模型 → 历史 → 节点视图。
显示已有特征的草图、实体、特征引用及特征参数引用关系，独立实体保持独立分支。
单击选中并定位历史步骤，双击或“编辑所选”打开原有参数编辑器。
拖动调整节点排列，滚动浏览，使用 + / − 缩放，“自动排列”恢复布局。
“启用 / 抑制”使用原有可撤销的特征命令。修改参数后，下次打开节点图会更新。
节点位置属于当前进程的界面状态，不改变模型文件格式。本版连线用于查看依赖。

铝型材工作台：点击顶部“铝型材” → 创建型材。
首批为固定截面目录：2020（公称槽6）、3030（公称槽8）、4040（公称槽8）。
只设置长度、起点中心位置、方向和截面旋转；截面由型号决定，不能修改槽宽、孔径或壁厚。
生成一个原生实体特征，支持预览、重新编辑、参数表达式、撤销和保存/打开。
加入新的截面型号时扩充固定目录，不通过拉伸变形改变已有型号的截面。
本库为原始实现的常用欧标系列截面模板，不代表所有供应商的同名型材或配件均相同。
几何模板保留四面 T 槽、斜向筋、中心通孔和外角圆角。没有复用供应商 CAD 资产。
公称尺寸参考：米思米公开的欧标经济型目录（仅参考尺寸事实）：
https://www.misumi.com.cn/pdf/vona/P1_202005_04.pdf
https://www.misumi.com.cn/pdf/vona/P2_202005_04.pdf
https://cn.c.misumi.com.cn/book/MSM1_M_C_19_02/pdf/0006.pdf
新增了保存用的原生特征类型；此版本保存的设计需要支持新格式的增强版打开。

连接件：铝型材 → 连接件 → 插入连接件。
首批固定厂商模型：Motedis S6BBR20（20系列槽6）、S8BBR30（30系列槽8）、S8IBR40（40系列槽8）。
保持原始几何尺寸，不缩放、不生成替代几何。只设置模型原点位置和 XYZ 旋转角度。
插入后是独立组件，可用同页“移动／复制”定位；本版为手动定位，还没有自动配对两根型材的槽位。
组件保留厂商料号、来源链接和槽系信息，BOM 可按零件统计。
CAD 模型来自厂商公开下载，独立安装在本机数据缓存中；源码和增量包不捆绑厂商 CAD 文件。
安装或验证数据：sh enhancements/fetch-connectors.sh [缓存目录]
默认缓存：SOLIDCRAFT_CONNECTOR_LIBRARY，或 XDG_DATA_HOME/solidcraft/connectors。
本机增强版启动器指定 ~/.local/share/solidcraft-snap/library/connectors。
下载脚本核对目录中的归档和 STEP 校验和，应用运行时离线读取已安装模型。
型号来源与校验和：enhancements/connector-catalog.json。

连接件预览：选择型号后，在插入面板内显示对应厂商 STEP 的等轴测图片。
鼠标停在预览图上可查看放大图。预览在后台生成并缓存，不向当前设计插入任何零件。
切换型号时只显示该型号的图片；尚未生成时显示加载状态，不复用上一型号的图。

通用铝型材工具与交互设计：enhancements/design/aluminium-workbench.txt。该文件为后续工具的设计稿，不代表其中规划功能已经实现。

骨架批量工具（可选高级用法）：
1. 铝型材 → 创建 → 矩形骨架：输入中心线宽、高，选择 XY / XZ / YZ 平面。
   创建普通可编辑草图，并带入原生宽高驱动尺寸；可在草图中编辑尺寸或使用已有参数表达式。
   整个骨架创建为一个撤销步骤，不绑定桌子、腿数或层数。
2. 铝型材 → 创建 → 沿线布置型材：选中骨架直线，或从“骨架草图”中选择整张草图。
   选固定 2020 / 3030 / 4040 型号、截面锚点与转角；每根直线生成独立实体，整批可一次撤销。
   “全部直线”包含草图中后续新增的直线；只选一部分则只驱动这些杆件。
   需要混用型号时分组选线、分别创建；同一条线重复使用会生成重叠实体，应避免重复布置。
3. 自由骨架：正常绘制二维或三维草图中的直线，再使用相同工具。支持空间斜杆、开放结构与分组。
   圆弧和曲线不被自动弯成型材。修改骨架后，杆件长度和方向跟随；双击杆件特征可更改型号和锚点。
本版矩形尺寸是中心线间距，不是加工后的外形尺寸。
接头端面暂不自动修剪，矩形拐角的杆件可能重叠；不能直接把中心线长度当成最终下料长度。
连接件目前仍使用已有的固定模型库和手动定位，不会自动跟随骨架。

模型接口交互（0.6.0）：
选中一根原始固定型号型材，在“铝型材”页直接显示模型交互点。
蓝色“＋”：两端沿轴向接出，四个侧面沿法向接出，使用对应的名义外侧面。
先点击母材侧面选择沿长度的位置，再点该侧“＋”；也可在预览中拖动起点沿母材调整位置。
拖动新型材末端调整长度，或在面板输入精确长度、型号、间隙和截面旋转，然后确认。
接续型材保存母材实体引用、接口、长度位置比例、间隙及装配路径；母材改长后接续点跟随。
创建后选中新型材，继续点击它的交互点即可接下一根。每次确认都是一个可撤销操作。
编辑接续型材时可“解除接续关联”，按当前位置转换为自由型材，确认后生效。
端部黄色连接件按钮：打开对应系列的固定角码库，在四个侧槽方向间切换，设置端部偏移。
模型中的 L 形导线表示安装拐角，面板中的图片预览来自实际厂商模型。确认后插入原尺寸 STEP。
角码预定位使用该厂商模型的 X=0、Y=0 安装面和 Z=0 宽度中心；不缩放。
此版连接件插入后仍为独立组件，不随母材后续改尺寸自动移动；请在结构尺寸确定后安装。
交互点目前针对未做后续裁切/布尔加工的原始目录型材；不把任意导入实体猜测成型材。
本版接续为直线外伸，尚不自动生成斜切端面，也不自动检查完整连接件套件或加工任务。
